# Formulário de Landing Pages — Doca Company

Formulário estático de captação de leads para a oferta de landing pages e sites da Doca Company.

## Implantação na Vercel

1. Importe este repositório na Vercel.
2. Selecione **Other** como framework, caso a plataforma solicite essa informação.
3. Não é necessário configurar comando de build.
4. Mantenha o diretório de saída vazio ou como a raiz do projeto.
5. Clique em **Deploy**.

O projeto usa apenas HTML, CSS e JavaScript e pode ser publicado diretamente.

## Integrações configuradas

- WhatsApp: redirecionamento sem mensagem predefinida.
- Webhook n8n: envio dos dados preenchidos.
- Google Planilhas: registro dos leads via Apps Script.
- Data Layer: evento personalizado `lead_landing`.

## Campos obrigatórios

- Nome
- Sobrenome
- Telefone
- E-mail
- Investimento atual em marketing
